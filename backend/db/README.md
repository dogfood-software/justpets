Generate migrations with `pnpm --filter @backend/db db:generate`, review the SQL under `src/migrations`, and commit the generated migration folders. Apply them locally with `pnpm db:migrate` and an explicit `DATABASE_URL`.

For Railway, keep the API service's Root Directory at the repository root and set its Railway Config File to `/backend/api/railway.json`. The API Dockerfile builds the migration runner and copies it and the SQL migrations into the runtime image. The configured pre-deploy command, `bun ./dist/migrate.js`, applies pending migrations before deploying the API and fails the deployment if migrations fail. Its timeout is 300 seconds.

The runner requires `DATABASE_URL` and resolves migration files relative to its own location. It uses a PostgreSQL session advisory lock to serialize overlapping runs and closes the connection on success or failure. Use a direct database connection for migrations; transaction pooling does not preserve session locks. Schema changes must remain compatible with the previous API version, which can still be serving requests while migrations run. Rolling back the API does not roll back the database.

The same bundle can later run in a CI release job with Neon: test migrations on a preview branch, apply committed migrations to production, then deploy the matching API revision only after success. Serialize releases for each database and remove Railway's pre-deploy step when CI owns production migrations.

Run `pnpm --filter @backend/db test` from the repository root to test migrations end to end. Docker must be running, with access to pull `postgres:18` on the first run. The test starts a fresh PostgreSQL instance, builds and runs the migration bundle in an isolated directory, checks database behavior, and reruns both the bundle and CLI to verify that existing data survives. It also checks missing configuration and migration failure with transaction rollback. The container, volumes, and temporary bundle are removed after the test, including on failure. The test supplies its own database URL.
